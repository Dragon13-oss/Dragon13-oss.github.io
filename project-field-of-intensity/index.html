Project 03

Field of Intensity

A wearable biofeedback interface translating heart rhythm into light, vibration, and projected visual fields.

2025WearableBiofeedbackProjection

Role

Interaction Designer / System Designer / Visual Designer / Researcher

Tools

Arduino, Pulse Sensor, TouchDesigner, LED Strip, Haptic Motor, Projection

Medium

Wearable biofeedback interface / projection-based visual system

Status

Functional prototype and design research exploration

Unlike ReadyMind, which explores rule-based presentation of body signals for human interpretation, this project treats bodily rhythm as perceptual material — translating pulse into light, vibration, and spatial atmosphere.

Origin

From Listening to Bodily Rhythm

The project began from instrumental music listening — noticing how breathing and heartbeat were subtly pulled by the surrounding sound. Rhythm emerged as something between body and environment, not simply a number to measure.

This project began my research trajectory: How can invisible bodily states become perceptible?

“I was not trying to read the music. I was staying inside its atmosphere.”

Design Question

How can bodily rhythm become a perceptual field?

Rather than classifying emotion, this project translates bodily intensity before interpretation.

Research Questions

What This Project Asks

01

How can invisible bodily states become perceptible without reducing them to numbers?

02

How should intensity map to light, motion and texture so the output remains legible as bodily rhythm?

System Logic

A Working Biofeedback Pipeline

This is not an aesthetic installation — it is a functional wearable prototype with sensing, data mapping and multi-modal feedback. The full signal chain runs in real time from finger to field.

01INPUT

Pulse Sensor

Infrared fingertip sensor captures heart rhythm as analog signal data.

→
02PROCESSING

Arduino Processing

Signal smoothing, BPM calculation and calibration. Serial data streams to TouchDesigner in real time.

→
03VISUAL MAPPING

TouchDesigner Mapping

BPM drives brightness, flow speed, particle density and colour channels through explicit parameter links.

→
04OUTPUT

LED / Haptic / Projection

Multi-modal output: LED strip glows, haptic motor pulses, projected visual field fills surrounding space.

Wearable Prototype

The Glove as Sensing and Feedback Interface

The wearable combines pulse sensing, LED visual feedback, haptic motor and wireless data transmission in a single glove. The hand is both sensor and display — the body becomes the interface.

Glove with pulse sensor and LED strips

LED feedback — intensity as brightness

Data to Sensation

Bodily Rhythm Becomes Visual Property

Pulse data flows through explicit parameter links in TouchDesigner. Each output channel represents one mapped dimension of intensity — together they produce a coherent, real-time visual field.

Brightness

Higher rhythm intensity increases overall light brightness across the visual field.

Flow Speed

Faster heartbeat accelerates the motion speed of flowing visual elements.

Particle Density

Greater intensity generates more visual particles — a denser, more saturated field.

A haptic motor provides tactile pulse feedback on the wrist, creating a real-time multisensory output pipeline from body signal to LED, vibration, and projection.

Testing & Iteration

Testing Shaped the Experience

Signal stability, wearable comfort and spatial clarity emerged as the main design criteria. Each problem became an opportunity to refine the embodied experience.

Unstable pulse readings

Finger movement caused serial values to fluctuate

→

Adjustment

Refined fingertip placement and calibration timing

Loose wiring

Cables interrupted LED and sensor response during movement

→

Adjustment

Shortened cable routing along wrist and back of hand

Projection visibility

Visual field lost clarity on bright surfaces

→

Adjustment

Increased contrast and simplified particle density

Feedback clarity

LED and haptic signals needed clearer separation

→

Adjustment

Separated LED and motor mapping into distinct intensity bands

Final Experience

Entering the Field

A three-stage experience: the body waits, connects through colour-coded intensity, then returns to a quiet fading trace. Each stage is visible to both participant and observer.

Waiting

01

Unconnected

The glove is present, but body signal and projection have not formed a response loop. Neutral light. Waiting body.

Active

02

Connected

Afterimage

03

Fading

When the loop disappears, colour and density fade into a quiet projected residue — an afterimage of presence.

Reflection

What I Learned

  • —Perception needs mapping, not measurement — the mapping favored felt intensity over numerical accuracy as a design choice, not a validated finding.
  • —The prototype ran as a functional end-to-end pipeline — sensing, mapping and feedback in one loop.
  • —Calibration and wiring were not engineering details; they shaped the experience.
Current Limitations

What This Prototype Cannot Show

Informal, small-scale testing

The experience was tried in informal sessions without a structured protocol.

Sensor stability

Pulse readings remained sensitive to finger placement and movement.

No formal evaluation

Outcomes were observed, not measured; perceptual meaning was not formally validated.
