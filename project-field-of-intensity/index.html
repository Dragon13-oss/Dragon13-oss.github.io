Project 03

Field of Intensity

A wearable biofeedback interface translating heart rhythm into light, vibration, and projected visual fields.

2025WearableBiofeedbackProjection

Role

Interaction Designer / System Designer / Visual Designer / Researcher

Tools

Status

Functional prototype and design research exploration

Unlike ReadyMind, which uses body signals as decision-support evidence for care, this project treats bodily rhythm as perceptual material — translating pulse into light, vibration, and spatial atmosphere.

Prototype Evidence

A working wearable biofeedback prototype with pulse sensing, real-time data mapping, LED and haptic feedback, and projected visual output — tangible proof that bodily rhythm can become perceptual material.

Origin

From Listening to Bodily Rhythm

The project began from instrumental music listening — noticing how breathing and heartbeat were subtly pulled by the surrounding sound. Rhythm emerged as something between body and environment, not simply a number to measure.

“I was not trying to read the music. I was staying inside its atmosphere.”

Design Question

How can bodily rhythm become a perceptual field?

Rather than classifying emotion, this project translates bodily intensity before interpretation.

System Logic

A Working Biofeedback Pipeline

This is not an aesthetic installation — it is a functional wearable prototype with sensing, data mapping and multi-modal feedback. The full signal chain runs in real time from finger to field.

Wearable Prototype

The Glove as Sensing and Feedback Interface

The wearable combines pulse sensing, LED visual feedback, haptic motor and wireless data transmission in a single glove. The hand is both sensor and display — the body becomes the interface.

Glove with pulse sensor and LED strips

LED feedback — intensity as brightness

Arduino sensing and serial output

Data to Sensation

Bodily Rhythm Becomes Visual Property

Pulse data flows through explicit parameter links in TouchDesigner. Each output channel represents one mapped dimension of intensity — together they produce a coherent, real-time visual field.

Brightness

Higher rhythm intensity increases overall light brightness across the visual field.

Flow Speed

Faster heartbeat accelerates the motion speed of flowing visual elements.

Particle Density

Greater intensity generates more visual particles — a denser, more saturated field.

A haptic motor provides tactile pulse feedback on the wrist, creating a multi-sensory loop between body signal and embodied response.

Prototype Validation

Testing Shaped the Experience

Signal stability, wearable comfort and spatial clarity emerged as the main design criteria. Each problem became an opportunity to refine the embodied experience.

Issue

Unstable pulse readings

Finger movement caused serial values to fluctuate.

Adjustment

Refined fingertip placement and calibration timing.

Issue

Loose wiring

Cables interrupted LED and sensor response during movement.

Adjustment

Shortened cable routing along wrist and back of hand.

Issue

Projection visibility

Visual field lost clarity on bright surfaces.

Adjustment

Increased contrast and simplified particle density.

Issue

Feedback clarity

LED and haptic signals needed clearer separation.

Adjustment

Separated LED and motor mapping into distinct intensity bands.

Functional testing and system integration

Documentation and final experience capture

Final Experience

Entering the Field

A three-stage experience: the body waits, connects through colour-coded intensity, then returns to a quiet fading trace. Each stage is perceptible to both participant and observer.
