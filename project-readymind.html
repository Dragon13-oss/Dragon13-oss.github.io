Prototype Evidence

A functional multimodal interface prototype was developed to translate body signals into visual readiness evidence for doctor-assisted timing decisions.

Problem

Is This the Right Moment to Go Deeper?

Before deeper psychological guidance begins, readiness matters. If the user is tense, unstable, or not prepared, continuing deeper support may become ineffective or unsafe.

Doctors can observe conversation and facial cues, but some stress signals may be hidden or difficult to judge visually. The design opportunity: how can multimodal body signals provide doctors with quiet, readable timing evidence?

Multimodal Input

Three Signal Layers

Three physiological and perceptual signals form an evidence layer for doctor review. Each signal is processed independently, then merged into a unified readiness indication.

Galvanic Skin Response

GSR

Skin conductance / stress-related arousal cue. One signal among several — not a standalone emotional state measure.

BPM via Pulse Sensor

Heart Rate

Beats per minute / physiological activation cue. Contributes to the evidence layer alongside other signals.

Facial Expression Tracking

MediaPipe

Facial expression state / external expression cue. Provides observable behavioral data for doctor review.

Decision Logic

A Transparent Rule System

Each signal passes through threshold logic. The outputs merge into a readiness score. The rule system is intentionally visible and interpretable.

BPM Threshold Logic

Heart rate → low (60–80) / mid (90–110) / high (110–200)

GSR Threshold Logic

Skin conductance → low (200–400) / mid (400–550) / high (550–700)

Physiological State Merge

Signal states combine via Math CHOP into a unified readiness value

Readiness Computation

Full merge chain → final readiness score and status output

Readiness Output

Three Possible States

The interface presents a readiness score (0–1) and one of three status labels. This is a cue for the doctor — not an automated diagnosis.

Ready

≥ 0.70

0.74

Signals appear relatively stable. Doctor may consider proceeding.

Observe

0.60 – 0.70

0.68

Mixed signals. Continue monitoring before proceeding.

Pause

< 0.60

—

Signals suggest waiting. Deeper guidance may be deferred.

These values are prototype interface states for design exploration — not clinically validated diagnostic thresholds. The system provides timing cues, not medical judgments.

Ethical Boundary

The System Supports Judgment, Not Therapy

Supports Judgment, Not Therapy

The system provides timing evidence. It does not deliver therapy, diagnosis, or treatment.

Doctor Remains Responsible

The doctor makes all final decisions. The system is a cue, not a directive.

A Cue, Not a Label

The output is a readiness indication — not an automated emotional diagnosis.

Body Signals Are Timing Evidence

Physiological signals are contextual cues — not a full emotional truth.
